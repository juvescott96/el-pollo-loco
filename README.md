# El Pollo Loco

A simple Jump-and-Run game built with an object-oriented approach in vanilla JavaScript, HTML and CSS.

## About the project

Help the character find coins and bottles to fight the enemy.

## Technologies

- JavaScript
- HTML5
- CSS3

## Architecture

Built with an OOP approach using multiple classes, organized in a dedicated `models` folder (e.g. `Character`, `Enemy`, `Coins`, `AnimatedObject`). Inheritance is used to structure and reuse code cleanly.
